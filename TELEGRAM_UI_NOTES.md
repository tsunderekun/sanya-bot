# Telegram: что стоит упростить в боте

Сверено с [официальным changelog](https://core.telegram.org/bots/api-changelog): Bot API 10.4 от 9 ноября 2026. Поддержка Telegram и поддержка установленным aiogram — разные вещи. Новые функции ниже не включены автоматически.

В локальном aiogram 3.32.0 есть поля для оформления кнопок, ephemeral-сообщений, а также методы для rich-сообщений и виджетов. Минимальная версия в `requirements.txt` этого не гарантирует; перед внедрением стоит проверить боевую версию и один реальный клиент Telegram.

| Возможность | Что дать пользователю | С чего начать |
| --- | --- | --- |
| `setMyCommands` и `BotCommandScope` | Короткое меню для лички, группы и админов | В групповом меню оставить частые команды, админские вынести в отдельную область. Русские алиасы оставить в обработчиках: в системном меню имя команды ограничено строчными латинскими буквами, цифрами и `_`. Видимость пункта не заменяет проверку прав. |
| `editMessageText`, `editMessageReplyMarkup`, `answerCallbackQuery` | Меню настроек в одном сообщении, короткое «сохранено» без сообщения в чат | Сначала заменить переходы «назад» и «все настройки» на редактирование, оставить проверку админства для каждого изменения. `callback_data` — до 64 байт. |
| `ForceReply` | Ввод слова или значения словаря без команды с длинным синтаксисом | Привязывать ожидаемый ответ к автору и исходному сообщению. Не использовать обычную reply-клавиатуру как постоянное меню. |
| `sendPhoto` с `has_spoiler`, `deleteMessage` | Картинка скрыта до клика; предупреждение исчезает после выбора | Уже применяется. Спойлер не делает картинку приватной: в группе её может открыть любой участник. |
| Ephemeral Messages (10.2–10.4) | Личные подсказки и результат для автора прямо в группе | Испытать на отдельном боте короткий ответ на кнопку. Для ответа на действие есть окно доставки; долгий поиск не должен полагаться на доставку ephemeral-ответа. Не переключать группу без проверки клиентов и SDK. |
| Rich Messages и черновики | Одна структурированная справка или постепенный вывод длинных ответов | Начать со справки в тестовой личке. Оставить обычный HTML и файл с длинным кодом запасными вариантами. Не показывать внутренние рассуждения модели. |
| HTML Widgets (10.4) | Отдельный интерфейс настроек в личке | Пока дорого по сравнению с кнопками. В production виджеты отправляются только в личку; inline-выдача виджетов пока недоступна. |

Короткие меню по областям и навигация в одном сообщении реализованы. При проверке в Telegram сравнить меню в личке и в группе под обычным участником и админом; затем пройти `/настройки` → раздел → «Все настройки». У словаря отдельное сообщение нужно только для ввода нового слова реплаем. Ephemeral-сообщения пока не включены. Ни один из этих механизмов не даёт боту полный список участников группы для `/all`.
