Аутентичный цифровой компаньон и бот для Telegram-конф, на 100% воспроизводящий характер, лексику, перекупский авито-вайб, франкенштейн-инженерию и брони-лор **Сани Пониёба** (@ponyeb228, в реале Саня / Александр). 

Бот полностью избавлен от корпоративной стерильности, шаблонных фраз ChatGPT и ИИ-слопа. Отвечает быстрыми пачками сообщений без точек, экспертно шарит за пайку, сокеты, перепрошивки и сети, разбирает фото плат и экранов через Vision, помнит локальный лор конфы и досье каждого кента.

## 🚀 Ключевые возможности

* **🔥 Аутентичная личность без цензуры:** живой перекупский сленг, мат к месту, ноль занудства, полное отсутствие точек на конце сообщений.
* **⚡️ Вариативный Burst Mode:** разбивка ответов на пачки от 2 до 5 коротких сообщений с естественными человеческими задержками между ними.
* **👁 Мультимодальность (Vision):** отправка фото материнок, сокетов, экранов с BSOD, артов и мемов — бот анализирует их через `moondream` и выдает сочный диагноз.
* **🎭 Фирменная стикерная система:**
  * Оцифровано 62 000 сообщений оригинала с точными весами его коронных стикеров (😱, 😵‍💫, 🙂, 😁, 🥹, 👄, 🦋, 🛌, 🍆).
  * 10 базовых наборов в кэше (~690 стикеров).
  * Реакция кита 🐳 на сообщения в чате (автоматически или с настраиваемым шансом).
* **🔍 Веб-поиск в реальном времени:** поиск цен на Авито, характеристик процессоров и свежих новостей через локальный SearXNG или DuckDuckGo.
* **🏛 Лор чатов и досье кентов (Append-Only):**
  * Факты о кентах и правила чатов сохраняются с уникальными номерами `[#ID]` без риска затереть историю.
  * Команды выборочного удаления `/delchat <ID>` и `/delkent <ID>`.
  * Авторское саммари по всей банде кентов `/kents` от первого лица Сани.
* **🛡 Динамические права администраторов:** управление лором конфы доступно создателю бота и администраторам конкретной группы.
* **🥊 Жесткая самооборона:** детекция наездов, скрытых вопросов-ловушек и троллинга с резким контрударом и переводом стрелок (без вежливости к провокаторам).
* **💻 Модуль генерации кода:** выдача готовых скриптов на Python / Bash блоками кода без симуляции терминала.

## 🛠 Быстрая установка (1 клик)

Установочник автоматически проверит зависимости, создаст виртуальное окружение, настроит модели Ollama и сконфигурирует `.env`.

### Вариант для Linux / macOS / WSL:
```bash
git clone https://github.com/ТВОЙ_ЛОГИН/sanya-bot.git
cd sanya-bot
chmod +x install.sh
./install.sh
```

### Вариант для Windows:
1. Склонируй репозиторий:
   ```cmd
   git clone https://github.com/ТВОЙ_ЛОГИН/sanya-bot.git
   cd sanya-bot
   ```
2. Дважды кликни по файлу **`install.bat`** (или запусти его в командной строке).

### Кроссплатформенный запуск через Python:
```bash
python3 install.py
```

## 📋 Конфигурация (`.env`)

Установочник создаст файл `.env` интерактивно, но вы всегда можете отредактировать его вручную:

```ini
# Токен бота от @BotFather (обязательно)
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ

# Адрес локального LLM-сервера Ollama
OPENAI_BASE_URL=http://localhost:11434
OPENAI_API_KEY=ollama
MODEL_NAME=sanya
VISION_MODEL_NAME=moondream

# Числовой Telegram ID суперадминов (через запятую)
ADMIN_IDS=123456789

# Скользящее окно памяти на чат (сообщений / символов)
MAX_HISTORY_LENGTH=25
MAX_CONTEXT_CHARS=14000

# SOCKS5 / HTTP прокси (оставьте пустым, если Telegram работает без блокировок)
TELEGRAM_PROXY=
SEARCH_PROXY=

# Веб-поиск (true/false) и движок ('duckduckgo' или 'searxng')
ENABLE_WEB_SEARCH=true
SEARCH_ENGINE=duckduckgo
SEARXNG_URL=http://localhost:8080

# Реакция кита 🐳 на сообщения (8% случайный шанс, 100% при упоминании "кит")
WHALE_REACTION_CHANCE=0.08

# Приоритет коронных стикеров Сани (98.5% топ, 1.5% остальные)
TOP_STICKERS_CHANCE=0.985
```

## 🐧 Автозапуск в фоне на Linux (systemd)

Установочник автоматически сгенерирует для вас файл службы `sanya-bot.service`. Чтобы включить автозапуск:

```bash
mkdir -p ~/.config/systemd/user
cp sanya-bot.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now sanya-bot.service
```

Просмотр логов работы бота в реальном времени:
```bash
journalctl --user-unit sanya-bot.service -f
```
