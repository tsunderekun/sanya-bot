[@ponyeb228_bot](https://t.me/ponyeb228_bot) — бот для дружеских чатов. Болтает, помогает с железом, ищет картинки и мемы, помнит лор конкретной конфы. В группе его можно позвать словом «Спермер», точным упоминанием `@ponyeb228_bot`, реплаем на его сообщение или командой. «Саня» и `@ponyeb228` бота не зовут.

## Команды

Если бот уже в конфе, для начала хватит `/help`. В меню Telegram — короткие списки для лички, группы и админов. Если команды в меню нет, её всё равно можно ввести вручную. Русские алиасы тоже работают, хотя в меню Telegram имена латинские.

| Команда | Что делает |
| --- | --- |
| `/хелп`, `/help` | Справка по категориям с кнопочной навигацией. |
| `/настройки`, `/settings` | Режим, тон, лор, автостикеры, словарь и пользовательские фразы обращения группы. Разделы открываются в одном сообщении; кнопка «Закрыть» убирает его из чата. |
| `/режим`, `/mode` | `норм` по умолчанию; `рофл` разрешает явно шуточный вымысел, но не меняет факты, поиск и оценки. |
| `/тон`, `/tone`, `/агрессия` | От 0 (дружелюбно) до 3 (жёсткий дружеский стёб). По умолчанию 1. |
| `/лор`, `/lore` | От 0 (только по запросу) до 3 (больше уместных отсылок). По умолчанию 1. |
| `/словарь`, `/dict` | Список слов, значение по запросу, `добавить слово = значение` и `удалить слово`. Встроенные записи защищены. |
| `/all`, `@all` | Позвать админов и известных боту действующих участников. Таймер общий для группы: 5 минут для админов, 15 для остальных. Это не полный список участников Telegram. |
| `/s`, `/поиск` | Веб-поиск через SearXNG или DuckDuckGo. |
| `/pic`, `/пикча` | Поиск картинок. Повтор запроса пропускает недавние выдачи этого чата по ссылке и содержимому файла. |
| `/booru`, `/r34`, `/derpi` | Поиск арта по тегам через запятую. Маршрут зависит от тегов, а не от имени команды. |
| `/slop`, `/слоп` | Поиск картинок только на AIBooru. Например, `/slop landscape, general`. |
| `/code`, `/код` | Написать код. Например, `/код Python, убрать дубли из списка`. |
| `/prompt`, `/промпт` | Написать позитивный и негативный промпты для картинки. Например, `/промпт пони ждёт трамвай ночью, акварель`. Картинку не генерирует. |
| `/stickeractivity`, `/автостикеры` | Частота автостикеров, отдельно для каждого чата. |
| `/мем`, `/meme` | Случайный мем из канала. На «хорс» бот иногда присылает локальный арт. |
| `/прекэш`, `/precache [канал] [страниц]` | Загрузить публичные медиа-посты из превью канала в пул мемов. Статус показывает просмотренные посты, новые записи и общий размер пула. |
| `/железо`, `/hardware` | Известная конфигурация автора или указанного кента. |
| `/оцени`, `/price` | Ориентир по объявлениям Авито, если данных достаточно. |
| `/стикер`, `/sticker` | Настоящий Telegram-стикер; `/stickers` показывает паки. Кит означает «угарнул». |

Случайный арт «хорс» — отдельная функция, не часть `/мем`: в группе на упоминание слова «хорс» или `horse` иногда отправляется PNG из `SLOIPER_DIR`. Есть шанс срабатывания и кулдаун на чат.

`/help` открывает справку по страницам: общение, поиск, инструменты, память и стикеры. Кнопками можно переключать разделы и перейти к настройкам.

Режим, тон, лор, словарь и фразы обращения настраиваются отдельно для каждого чата. В группе их меняют администраторы. Фразу добавляют ответом на панель «Фразы обращения»; включение/выключение не удаляет запись.

Если стикеры лезут чаще, чем хотелось бы, открой `/автостикеры` или нажми нужную кнопку в `/настройки`. Уровни: `0` — выключить, `1` — 10%, `2` — 25%, `3` — 50%. Шанс считается на каждый обычный разговорный ответ, а не на каждую его строку. Это случайный выбор, не строгая очередь «через один». Для подписей к картинкам стикер по-прежнему должен предложить сам бот. `default` возвращает прежнее поведение: шанс для разговора применяется только когда модель предложила стикер. Ручной `/стикер` и реакция кита живут отдельно.

### Как выбирается источник арта

- `пони`, `pony`, `MLP`, `млп`, `My Little Pony` и известные имена персонажей вроде `флаттершай` направляют запрос **только на Derpibooru**. Пример: `/booru млп, solo, safe`.
- Остальные теги ищутся на Gelbooru, Konachan, e621 и, при настроенном доступе, Rule34.xxx. Без указанного рейтинга бот не добавляет `safe` или `general`, но перед поиском просит автора нажать «Да, я понимаю»: в выдаче может быть контент 18+. Подтверждение одноразовое, действует три минуты, результат приходит под спойлером.
- Чтобы искать только безопасную выдачу без подтверждения, добавь `, safe` или `, general` (также работает `rating:safe` или `rating:general`). Бот учитывает разметку рейтингов, которую возвращает площадка.
- При поиске по одному тегу бот берёт посты с оценкой выше 25. Если результатов нет, попробуй несколько тегов через запятую. Последние 200 ID отправленных артов хранятся отдельно для каждого чата.
- Rule34.xxx требует `RULE34_USER_ID` и `RULE34_API_KEY` из настроек аккаунта. Без них бот пропускает источник. Ключ хранится в `.env`, не в Git и не в сообщениях.
- `/slop` не ходит по другим бордам, даже если в тегах есть MLP. Без рейтинга сначала появится «Да, я понимаю»: нажать может только автор. Бот уберёт предупреждение и пришлёт результат под спойлером. Спойлер не делает картинку приватной: открыть её может любой участник группы. Для безопасной выдачи на AIBooru `safe` и `general` означают рейтинг `g`. Если задан `SEARCH_PROXY`, и поиск, и загрузка картинки с AIBooru идут через него.
- `/идея` (`/promptidea`) предлагает случайную NSFW-сцену для генерации картинки. Поиск тегов и генерация начинаются только после одноразового подтверждения автора; предупреждение действует три минуты. Используются только явно взрослые вымышленные персонажи. Бот выдаёт позитивный и негативный текст под спойлером, картинку не скачивает и не отправляет. Спойлер в группе не делает текст приватным.
- Фразы обращения в `/настройки` не зависят от регистра и повторных пробелов; совпадение учитывает границы слов. Фразы не переносятся между чатами.
- Для Rule34.xxx `SEARCH_PROXY` используется только для скачивания картинок с CDN. Запросы к API с ключом идут напрямую.

## Лор и память

- `/лорконфы` (`/setchat`) открывает факты этой конфы. `/кент` (`/setkent`) открывает список кентов; вызови команду реплаем, чтобы сразу открыть нужного. В обоих меню админы могут дописать факт реплаем на подсказку или удалить запись с подтверждением. «Закрыть» убирает панель из чата.
- Старые команды тоже работают: `/setchat <факт>`, `/setkent @ник <факт>` (можно указать ID или вызвать команду реплаем), `/delchat <ID>` и `/delkent <ID>`. `/kents` показывает сводку, а `/лор` настраивает частоту отсылок.
- `/досье` (`/mydata`) показывает свои данные. Чужое досье ограничено текущей группой и не раскрывает личные заметки.
- Короткие явные самоописания вроде «Люблю джаз» бот запоминает в группе без ответа и реакции. Вопросы, планы, цитаты и сведения о других не идут в тихую память. Записи не переносятся между чатами и не меняют ручной лор.
- У каждого свой разговор с Саней в каждой конфе. Если отвечаешь реплаем, бот смотрит на эту цепочку, а не на соседние разговоры. Когда история не влезает в запрос к модели, Саня оставляет свежие реплики как есть и пытается сжать ближайший старый отрывок. Сводка в базу не записывается.
- `/facts` показывает свои тихие факты группы; `/forgetme` позволяет удалить свои сообщения и тихие факты, не стирая ручной лор при обычной очистке. `/clear` очищает историю текущего чата (в группе — только админ).

Не добавляйте в лор личные данные или конфиденциальную информацию. Неизвестный лор бот не должен додумывать.

Если Саня не реагирует в группе, попробуй `/help@ponyeb228_bot` или ответь на его сообщение. Если команда доходит, а обычные сообщения — нет, проверь Privacy Mode в @BotFather. Не выдавай боту лишние права только ради `/all`: Telegram всё равно не даёт ему выгрузить полный список участников.

## Запуск

Нужны Python 3.10+, токен Telegram от @BotFather и работающий Ollama с настроенной разговорной моделью. Для разбора фото нужна модель Vision; для OCR — Tesseract с языками `rus` и `eng`.

```bash
git clone https://github.com/tsunderekun/sanya-bot.git
cd sanya-bot
python install.py
```

Можно использовать `install.sh` на Linux/macOS или `install.bat` на Windows. При ручной установке создай виртуальное окружение, установи `python -m pip install -r requirements.txt`, скопируй `.env.example` в `.env` и заполни `TELEGRAM_BOT_TOKEN`, `MODEL_NAME`, `OPENAI_BASE_URL` и при необходимости `ADMIN_IDS`. Точка входа — `python bot.py`.

Дополнительные настройки: `SEARCH_ENGINE` и `SEARXNG_URL` для поиска, `TELEGRAM_PROXY` и `SEARCH_PROXY` для прокси, `MEME_DONOR_CHANNEL_IDS` для доноров мемов, `SLOIPER_DIR` для локальных PNG, `OCR_ENABLED` и `TESSERACT_CMD` для OCR. Все параметры и умолчания — в [`sanya/config.py`](sanya/config.py).

На Linux установщик создаёт шаблон пользовательской службы. После копирования в `~/.config/systemd/user/`:

```bash
systemctl --user daemon-reload
systemctl --user enable --now sanya-bot.service
journalctl --user -u sanya-bot.service -f
```

Код бота находится в `sanya/`, тесты — в `tests/`. Диалоги и настройки хранятся в SQLite; перед работой с существующей базой см. [MIGRATION.md](MIGRATION.md) и [BOT_HANDOFF.md](BOT_HANDOFF.md).

```bash
python -m unittest discover -s tests -q
python -m ruff check sanya tests update_kents_db.py --select F,I
```

### Как поручить развёртывание агенту

Дай агенту адрес и пользователя для SSH, каталог установки, ветку или коммит и адрес Ollama. Токен положи на сервер сам или передай через менеджер секретов. В переписку и в Git его скидывать не надо.

1. **Перед запуском:** найти действующую службу, её рабочий каталог, `.env` и реальный `DB_PATH`. Не выводить значения секретов. Если бот уже работает, не запускать второй polling с тем же токеном и не перетирать локальные правки.
2. **Подготовка:** развернуть выбранный коммит в отдельном каталоге, создать `venv`, установить `requirements.txt`, прогнать тесты. На новой установке настроить `.env` с правами `0600`; для работы нужна доступная модель Ollama. Проверить, что рабочая база не подменяется тестовой.
3. **Перед обновлением существующей установки:** сделать согласованную SQLite-копию через SQLite backup API (или после остановки при корректно закрытой БД), сохранить предыдущий код и конфиг службы. Проверить открытие копии и `PRAGMA integrity_check`. Не применять миграцию ручного лора без отдельного согласования.
4. **Запуск:** для Linux использовать пользовательскую службу `sanya-bot.service`, `WorkingDirectory` на каталог бота и `ExecStart` с абсолютными путями до `venv/bin/python` и `bot.py`. После смены unit выполнить `systemctl --user daemon-reload`, запустить или перезапустить службу и проверить `is-active` и журнал текущего запуска. Если нужен старт без залогиненного пользователя, отдельно согласовать настройку linger на сервере.
5. **Приёмка:** подтвердить старт polling, отсутствие цикла перезапусков и работу команды в тестовом чате. Если не заработало — вернуть предыдущий код и unit; копию БД восстанавливать только при необходимости и отдельно от отката кода. Не отправлять тестовые сообщения в рабочую группу без согласования.
