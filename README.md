# Саня Пониёб — Telegram-бот

[@ponyeb228_bot](https://t.me/ponyeb228_bot) — бот для дружеских чатов. Болтает, помогает с железом, ищет картинки и мемы, помнит лор конкретной конфы. В группе его можно позвать словом «Спермер», точным упоминанием `@ponyeb228_bot`, реплаем на его сообщение или командой. «Саня» и `@ponyeb228` бота не зовут.

## Команды

| Команда | Что делает |
| --- | --- |
| `/хелп`, `/help` | Полная справка с примерами. |
| `/настройки`, `/settings` | Меню режима, тона, лора и словаря. |
| `/режим`, `/mode` | `норм` по умолчанию; `рофл` разрешает явно шуточный вымысел, но не меняет факты, поиск и оценки. |
| `/тон`, `/tone`, `/агрессия` | От 0 (дружелюбно) до 3 (жёсткий дружеский стёб). По умолчанию 1. |
| `/лор`, `/lore` | От 0 (только по запросу) до 3 (больше уместных отсылок). По умолчанию 1. |
| `/словарь`, `/dict` | Список слов, значение по запросу, `добавить слово = значение` и `удалить слово`. Встроенные записи защищены. |
| `/all`, `@all` | Позвать админов и известных боту действующих участников. Таймер общий для группы: 5 минут для админов, 15 для остальных. Это не полный список участников Telegram. |
| `/s`, `/поиск` | Веб-поиск через SearXNG или DuckDuckGo. |
| `/pic`, `/пикча` | Поиск картинок. Повтор запроса пропускает недавние выдачи этого чата по ссылке и содержимому файла. |
| `/booru`, `/r34`, `/derpi` | Поиск арта по тегам через запятую. Маршрут зависит от тегов, а не от имени команды. |
| `/мем`, `/meme` | Случайный мем из канала. На «хорс» бот иногда присылает локальный арт. |
| `/железо`, `/hardware` | Известная конфигурация автора или указанного кента. |
| `/оцени`, `/price` | Ориентир по объявлениям Авито, если данных достаточно. |
| `/стикер`, `/sticker` | Настоящий Telegram-стикер; `/stickers` показывает паки. Кит означает «угарнул». |

Режим, тон, лор и словарь настраиваются отдельно для каждого чата. В группе их меняют администраторы. Без аргумента команды настроек открывают меню.

### Как выбирается источник арта

- `пони`, `pony`, `MLP`, `млп`, `My Little Pony` и известные имена персонажей вроде `флаттершай` направляют запрос **только на Derpibooru**. Пример: `/booru млп, solo, safe`.
- Остальные теги ищутся на Gelbooru, Konachan, e621 и, при настроенном доступе, Rule34.xxx. Для этих источников бот запрашивает безопасный рейтинг и проверяет его в ответе API; оценка рейтинга зависит от разметки площадки.
- При поиске по одному тегу бот берёт посты с оценкой выше 25. Если результатов нет, попробуй несколько тегов через запятую. Последние 200 ID отправленных артов хранятся отдельно для каждого чата.
- Rule34.xxx требует `RULE34_USER_ID` и `RULE34_API_KEY` из настроек аккаунта. Без них бот пропускает источник. Ключ хранится в `.env`, не в Git и не в сообщениях.

## Лор и память

- `/setchat` показывает ручной лор группы; `/setchat <факт>` добавляет запись, `/delchat <ID>` удаляет конкретную запись.
- `/setkent` добавляет ручной факт о кенте: ответь командой на его сообщение, укажи числовой ID или известный `@ник`. `/delkent <ID>` удаляет запись. `/kents` показывает сводку.
- `/досье` (`/mydata`) показывает свои данные. Чужое досье ограничено текущей группой и не раскрывает личные заметки.
- Короткие явные самоописания вроде «Люблю джаз» бот запоминает в группе без ответа и реакции. Вопросы, планы, цитаты и сведения о других не идут в тихую память. Записи не переносятся между чатами и не меняют ручной лор.
- `/facts` показывает свои тихие факты группы; `/forgetme` позволяет удалить свои сообщения и тихие факты, не стирая ручной лор при обычной очистке. `/clear` очищает историю текущего чата (в группе — только админ).

Не добавляйте в лор личные данные или конфиденциальную информацию. Неизвестный лор бот не должен додумывать.

## Запуск

Нужны Python 3.10+, токен Telegram от @BotFather и работающий Ollama с настроенной разговорной моделью. Для разбора фото нужна модель Vision; для OCR — Tesseract с языками `rus` и `eng`.

```bash
git clone https://github.com/tsunderekun/sanya-bot.git
cd sanya-bot
python install.py
```

Можно использовать `install.sh` на Linux/macOS или `install.bat` на Windows. При ручной установке создай виртуальное окружение, установи `python -m pip install -r requirements.txt`, скопируй `.env.example` в `.env` и заполни `TELEGRAM_BOT_TOKEN`, `MODEL_NAME`, `OPENAI_BASE_URL` и при необходимости `ADMIN_IDS`. Точка входа — `python bot.py`.

Дополнительные настройки: `SEARCH_ENGINE` и `SEARXNG_URL` для поиска, `TELEGRAM_PROXY` и `SEARCH_PROXY` для прокси, `MEME_DONOR_CHANNEL_IDS` для доноров мемов, `SLOIPER_DIR` для локальных PNG, `OCR_ENABLED` и `TESSERACT_CMD` для OCR. Все параметры и умолчания — в [`sanya/config.py`](sanya/config.py).

На Linux установщик создаёт шаблон пользовательской службы. После копирования в `~/.config/systemd/user/`:

```bash
systemctl --user daemon-reload
systemctl --user enable --now sanya-bot.service
journalctl --user -u sanya-bot.service -f
```

Код бота находится в `sanya/`, тесты — в `tests/`. Диалоги и настройки хранятся в SQLite; перед работой с существующей базой см. [MIGRATION.md](MIGRATION.md) и [BOT_HANDOFF.md](BOT_HANDOFF.md).

```bash
python -m unittest discover -s tests -q
python -m ruff check sanya tests update_kents_db.py --select F,I
```
