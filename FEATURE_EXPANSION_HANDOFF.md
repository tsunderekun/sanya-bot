# Расширение функционала: установка и проверка

Реализация [ТЗ](TASK_FEATURE_EXPANSION.md). Рабочая БД не изменялась, деплоя и перезапуска не было.

## Обновление SQLite

Остановить бота и сделать SQLite-бэкап штатным механизмом SQLite (файл WAL не копировать отдельно). При запуске `python bot.py` инициализация создаст две таблицы, если их нет: `channel_memes` (Telegram `file_id`, без подписей) и `booru_history` (последние 200 выданных ID на чат). Старые записи не мигрируются и не удаляются. `update_kents_db.py` для этой задачи не нужен.

## Настройка

- `/мем` / `/meme`: добавлять бота только в каналы, разрешённые для раздачи медиа в других чатах. Новые открытые посты из публичных каналов попадают в общий пул; для согласованных приватных каналов указать числовые ID в `MEME_DONOR_CHANNEL_IDS` через запятую. Защищённые, платные и скрытые спойлером посты не сохраняются. При пустом пуле бот пробует публичное превью МДМ и передаёт URL напрямую Telegram; веб-превью может менять разметку, а CDN — истекать. Старые посты каналов через Bot API не импортируются.
- «Хорс»: распаковать проверенные PNG из `sloiper.zip` в `data/sloiper/` на сервере или указать `SLOIPER_DIR`. Архив и картинки не входят в коммит. Шанс `SLOIPER_CHANCE=0.4` по умолчанию; после попытки отправить найденный арт действует 150-секундный кулдаун на чат. `SLOIPER_CHANCE=0` выключает триггер. Явное обращение к боту и тихая память имеют приоритет.
- OCR: установить Tesseract и языковые данные `rus` + `eng` (Debian/Ubuntu: `tesseract-ocr`, `tesseract-ocr-rus`, `tesseract-ocr-eng`). Бинарник в `PATH` или задать `TESSERACT_CMD`; `OCR_ENABLED=false` отключает OCR. При недоступности OCR остаётся vision. Распознанный текст передаётся локальной модели как данные, не записывается отдельным фактом и не включается в веб-поиск.
- `/booru`: Derpibooru, Gelbooru и Konachan. Один тег даёт порог качества и подсказку; без явно выбранного рейтинга используется безопасный рейтинг. Поддержка нестандартных рейтингов зависит от источника; Gelbooru может ограничивать доступ к API. История различает источники; зеркала одной картинки с разными ID считаются разными.
- `/оцени` / `/price`: нужны включённый веб-поиск и минимум три подходящих объявления с видимой ценой. Вилка и быстрая продажа — ориентиры по ценам предложений в выдаче, не проверенные сделки и не гарантия актуальности объявления. `/железо` без аргументов читает автофакты только этого чата, с именем кента — подтверждённое железо из лора.

## Проверка после согласованного запуска

В тестовом чате проверить `/мем` с пустой БД и после публикации фото, видео и GIF в донорском канале; убедиться, что подписи не уходят. Затем проверить «хорс» с реальным PNG, `/booru fluttershy` дважды, русский и английский OCR на скриншоте, `/железо` после фразы «У меня RTX 3070», `/железо витек` и `/оцени RTX 3070`. Экспертный ИИ-блок включается в `CHAT` / `DETAIL` примерно на 10% подходящих ответов; отдельно проверить живой тон на Ollama.
